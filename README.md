# 사기경마 · 반별 대결

- `host.html`: 교사용(프로젝터) 화면. 게임 만들기, 시작, 일시정지, 정산을 해요. **게임 중에는 이 창이 시계 역할을 하니 닫지 마세요.**
- `index.html`: 학생 화면. 주소 뒤에 `#게임코드`가 붙어 있으면 바로 입장해요.
- `logic.js`: 정답·단서·레이스 생성 (교사 화면에서만 실행)
- `fb.js`: Firebase 연결 설정
- `firestore.rules`: Firestore 보안 규칙

## 처음 한 번만
1. Firebase 콘솔 → Firestore → 규칙 탭에 `firestore.rules` 내용을 통째로 붙여 넣고 **게시**
2. Authentication → 로그인 방법 → **익명** 사용 설정
3. 이 폴더의 파일 5개를 GitHub 저장소에 올리고 Settings → Pages에서 배포

## 수업할 때
1. `https://(아이디).github.io/(저장소)/host.html`을 프로젝터 PC에서 열고 **게임 만들기**
2. 화면의 QR·주소·코드로 학생 입장 → 반·번호·이름 입력
3. **게임 시작** → 라운드마다 단서 자동 공개, 3·6·9라운드 뒤 작전 시간
4. 12라운드가 끝나면 자동 정산 (반 점수 = 1인 평균 칩)
